Bengaluru Home Price Predictor

A machine learning powered web application that estimates property prices in Bengaluru based on property characteristics.

How It Works

1

Enter Property Details

Provide the area, BHK, bathrooms and location of the property.

2

Machine Learning Model

The trained Linear Regression model processes the property information.

3

Price Prediction

The application returns an estimated property price in Indian Lakh.
